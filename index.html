Langkah integrasi

Siapkan koneksi sebelum mengaktifkan kontrol nyata.

  1. Pastikan perangkat muncul di Tuya Smart / Smart Life.Gunakan akun dan rumah yang benar.
  2. Buat project Smart Home Cloud di Tuya Developer Platform.Pilih data center sesuai region akun/perangkat, lalu otorisasi layanan yang diperlukan.
  3. Hubungkan akun aplikasi dan ambil ID perangkat.Pastikan project punya izin membaca status dan mengirim perintah.
  4. Petakan data point (DP) perangkat.Nama kode untuk switch, tegangan, arus, daya, dan energi berbeda-beda antar model.
  5. Masukkan kredensial ke backend server.Jangan pernah menaruh Access ID/Secret di HTML atau JavaScript browser.
